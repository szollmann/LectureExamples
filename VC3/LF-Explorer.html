Interactive light-field renderer

Drag in the scene to move a virtual camera. Click a point in the scene to select an output image coordinate.

The u,v plane is the camera array: each thumbnail is one captured input view. Click a thumbnail to select that viewpoint.
Ray space: selected output point ((s,t)) receives samples from source viewpoints ((u,v)).

The scene is synthetic so that foreground, middle-ground, and background have clearly different parallax. The construction illustrates the paper’s idea: a light field is (L(u,v,s,t)), not one fixed image.
